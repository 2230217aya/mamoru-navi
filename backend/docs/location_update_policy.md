# 位置情報更新間隔の仕様

## 更新間隔
位置情報の送信間隔は、初期仕様として30秒ごととする。
ただし、実際の利用状況やバッテリー消費、通信量、混雑判定の精度を確認しながら、必要に応じて更新間隔を変更できるものとする。

## 古い位置情報の扱い
最終更新時刻から5分以上経過した位置情報は、古い情報として扱う。

## 混雑判定で使用するデータ
混雑判定では、最終更新から5分以内の位置情報のみを使用する。

## 理由
位置情報を高頻度で更新しすぎると、端末のバッテリー消費や通信量が増える可能性がある。

本アプリでは、ナビアプリのように秒単位で正確に移動経路を追跡することよりも、避難所やエリアごとの混雑状況を把握することを目的としている。

そのため、リアルタイム性と端末負荷のバランスを考慮し、初期仕様では30秒ごとの更新とする。

また、古い位置情報を混雑判定に使用すると、すでに移動したユーザーまで人数に含まれる可能性がある。

そのため、最終更新から5分以上経過した位置情報は、混雑判定の対象外とする。
