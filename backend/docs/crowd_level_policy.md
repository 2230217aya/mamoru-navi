# 混雑度の基準設定

## 混雑度の判定基準
混雑度は、避難所の収容人数に対する現在人数の割合をもとに判定する。
現在人数は、避難所エリア内にいるユーザー数を集計した値を使用する。
収容人数は、`shelters.capacity`を使用する。

## 混雑率の計算方法
混雑率は以下の式で算出する。
```txt
混雑率 = 現在人数 / 収容人数
```
例：
現在人数：80人
収容人数：100人
混雑率：80%

## 混雑度の分類
混雑率に応じて、以下の4段階で混雑度を判定する。
| 混雑率       | 表示   | 説明            |
| --------- | ---- | ------------- |
| 0% 〜 49%  | 空きあり | 余裕がある状態       |
| 50% 〜 79% | やや混雑 | 利用者が増えてきている状態 |
| 80% 〜 99% | 混雑   | 収容人数に近づいている状態 |
| 100%以上    | 満員   | 収容人数以上の状態     |

## capacityが0の場合
`capacity`が0または未設定の場合は、混雑率を計算できないため、混雑度は`unknown`として扱う。

## 理由
混雑度を数値だけで表示すると、利用者が直感的に判断しにくい可能性がある。

そのため、現在人数と収容人数から混雑率を算出し、段階的な表示に変換することで、避難所の状況を分かりやすく伝えられるようにする。

また、混雑度の基準を事前に定義しておくことで、後続の混雑度変換処理やヒートマップ用データ生成APIで同じ基準を利用できる。
